# CreatorAI Studio v1

Working Node/Express AI studio with AI Creator, AI Video, AI Ads, AI Coding and a video production planner.

## Start
1. Install Node.js 20+.
2. Copy `.env.example` to `.env`.
3. Add your AI API key to `OPENAI_API_KEY`.
4. Run `npm install` then `npm start`.
5. Open http://localhost:3000.

The API key stays on the server. The video planner creates a real structured render manifest; connecting a real MP4 rendering provider is the next production integration.
